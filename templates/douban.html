豆瓣配置
你的豆瓣个人主页URL中的数字部分，如 https://www.douban.com/people/205120931/
浏览器打开豆瓣 → F12 → Network → 任意请求 → Headers → Cookie
自动同步

按 cron 表达式定时全量拉取豆瓣观影记录，自动写入数据库（每15部为一页，保持豆瓣顺序）。

格式：分 时 日 月 周（标准5段式）。常用：
0 3 * * * = 每天3:00  |  0 */6 * * * = 每6小时  |  0 3 * * 1 = 每周一3:00
同步电影

获取你豆瓣"看过的电影"列表，自动获取简体中文名。与现有数据对比后同步到系统中。
